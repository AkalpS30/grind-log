# Grind Log

## Problem
DSA prep only works if problems get revisited, not just solved once.
Right now there's no way to know which of the problems I solved two
or three weeks ago are fading from memory — they just disappear into
old notes or get forgotten entirely. That's a real risk over a six-month
prep window: solving something once means nothing if I can't reproduce
it under interview pressure later.

## Who it's for
Just me, for now. Opened once a day, usually right after a problem-solving
session, to log what I did and check what's due for review based on how
confident I felt last time.

## Features (v1)
- Log a solved problem (title, topic, difficulty, source link, time taken, confidence 1-5)
- "Due today" view based on a spaced-repetition schedule
- History table, filterable by topic and difficulty
- GitHub commit activity panel (last 30 days)
- Data persists across page refresh
- Responsive layout (works on mobile)

## Out of scope (for v1)
- No user accounts or login
- No backend or database
- No framework (React, etc.) — plain HTML/CSS/JS only
- No charting library

## Stack
HTML, CSS, JavaScript (vanilla)
